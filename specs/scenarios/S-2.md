# Сценарий S-2: Прогресс онбординга

## Цель
Пользователь хочет узнать, какие задачи остались невыполненными в его чеклисте.

## Контекст
*   **Роль:** Стажёр.
*   **Инструмент:** checklist_get_plan.

## Шаги обработки
1.  **Запрос:** "Что мне осталось сделать?"
2.  **Действие агента:** Вызывает checklist_get_plan(user_id=current_user).
3.  **Ответ системы:** Список незакрытых пунктов с дедлайнами.
4.  **Генерация:** Агент ранжирует задачи по срочности (ближайший дедлайн первым).

## Ожидаемый результат
"У тебя осталось 3 задачи: 1. Доступ к GitLab (дедлайн сегодня), 2. Знакомство с командой (завтра)...".
