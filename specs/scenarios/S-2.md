# S-2: Ответ по базе знаний

Номер соответствует [MVP](../../docs/mvp.md). RAG подключён к чату. Нужны индексация E5 и рабочая LLM.

## Проверка

Спросить о code review. Проверить постепенный ответ и источник. Затем спросить о теме, которой нет в KB.

## Ожидаемый результат

Ответ основан на доступном материале, источник содержит document_id и revision. При отсутствии сведений помощник признаёт это. После перезагрузки ответ и источники сохранены; чужие документы не возвращаются.

Результат прогона фиксируется отдельно с коммитом и окружением. Этот сценарий
задаёт приёмку, а не объявляет её успешно пройденной.
