# Сценарий S-6: Правила работы с данными

## Цель
Пользователь спрашивает о допустимости использования персональных данных клиентов в тестах.

## Контекст
*   **Роль:** Любой сотрудник.
*   **База знаний:** Документы 13-learning-library.md, 14-data-ethics.md.

## Шаги обработки
1.  **Запрос:** "Можно ли использовать реальные имена клиентов в логах?"
2.  **Поиск:** Агент находит строгий запрет в политике этики данных.
3.  **Генерация:** Агент категорично отвечает "Нет" и цитирует пункт запрета.
4.  **Предупреждение:** Агент напоминает о последствиях нарушения (дисциплинарное взыскание).

## Ожидаемый результат
Жесткое соблюдение compliance-правил. Никаких компромиссов.
