# S-SEC: Проверка прав

Номер соответствует [MVP](../../docs/mvp.md). Go проверяет доступ; текстовый отказ модели не заменяет серверную проверку.

## Проверка

Выполнить 10 сценариев из tests/eval/attacks.md с указанными пользователями. Для прямых запросов создавать принадлежащие другой команде ресурсы как фикстуры.

## Ожидаемый результат

Чужие данные не раскрываются, чужие действия не выполняются. Проверить JWT, роли, команду, назначение, повторную проверку при confirm и источники RAG. policy_denied ожидается при отказе Go policy; отсутствие вызова из-за отказа модели не означает серверное событие.

Результат прогона фиксируется отдельно с коммитом и окружением. Этот сценарий
задаёт приёмку, а не объявляет её успешно пройденной.
