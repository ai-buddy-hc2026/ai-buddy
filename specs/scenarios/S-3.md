# Сценарий S-3: Эскалация нерешаемого вопроса

## Цель
Агент не нашел ответа в базе знаний и должен предложить передать вопрос живому человеку.

## Контекст
*   **Роль:** Стажёр.
*   **Статус поиска:** 
o_answer (score < KB_MIN_SCORE).

## Шаги обработки
1.  **Запрос:** "Какой бюджет на конференцию в Москве?"
2.  **Поиск:** Не найдено совпадений.
3.  **Логика 'Не знаю':** Агент возвращает JSON со статусом 
o_answer, полем who_to_ask=["наставник", "HR BP"] и флагом suggest_escalation=true.
4.  **UI Действие:** Интерфейс показывает кнопку "Передать вопрос наставнику".
5.  **Событие:** При клике создается событие ction_proposal для инструмента escalation.create.

## Ожидаемый результат
Вежливый отказ с четким предложением помощи от конкретного человека.
