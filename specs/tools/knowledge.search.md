# knowledge.search

Поиск по базе знаний (RAG). Реализация: `ai-service/app/rag/search.py`, обёртка для агента: `app/agent/knowledge_tool.py`.

## Вход
| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| query | string | да | Вопрос пользователя своими словами |

Параметр `team_id` из контракта MCP модель не передаёт. Агент подставляет его из контекста пользователя. Если модель всё же передаст `team_id`, он игнорируется.

## Выход
Найдено (`status: found`): до 4 фрагментов с оценкой не ниже порога `KB_MIN_SCORE`.
```json
{
  "status": "found",
  "results": [
    {"id": 1, "doc_title": "Code review в команде", "section": "Как проходит ревью",
     "text": "...", "score": 0.87, "source": "seed"}
  ]
}
```
Ничего не найдено (`status: no_answer`):
```json
{"status": "no_answer", "who_to_ask": ["наставник", "руководитель", "HR BP"], "suggest_escalation": true}
```
Пустой результат не считается ошибкой. Агент отвечает «не знаю» и не придумывает ответ.

`source`: seed (документы базы) или mentor_answer (ответ наставника, сценарий S-6).

## Права и область данных
Доступен всем ролям. Видны общие документы (`team_id` пустой) и документы команды пользователя. Чужие командные документы не возвращаются.

## Ошибки
| Код | Когда |
|---|---|
| empty_query | пустой запрос |
| search_unavailable | модель эмбеддингов или БД недоступны |

## События
`answer_with_source` при found, `answer_unknown` при no_answer.

## Параметры
`KB_TOP_K` (4), `KB_MIN_SCORE` (подбирается скриптом calibrate_threshold.py), модель `intfloat/multilingual-e5-base`, размерность 768.
