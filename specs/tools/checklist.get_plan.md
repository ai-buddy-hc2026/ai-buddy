# checklist.get_plan

План адаптации. Действующий профиль реализации.

## Вход и права

Вход: необязательный `intern_id` (UUID); для buddy/lead обязателен. Intern читает только свой план, buddy - назначенных стажёров, lead - свою команду.

## Поведение

Ответ содержит stage, tasks, progress и next_step. Следующая задача выбирается по этапу, позиции и ID среди не done, включая blocked и задачи наставника. Подтверждение не требуется.

## Контракт и ошибки

Точные JSON Schema и примеры: [MCP, раздел 5](../../docs/mcp.md#5-данные-и-json-schema).
Ответ MCP имеет ok/data либо ok/error; коды ошибок и retryable определены
в [разделе 7](../../docs/mcp.md#7-ошибки-и-повторы). Go проверяет права при каждом вызове.
Внутренние ID - UUID; внешний номер заявки сохраняет формат интеграции.
