# absences.create_request

Создание отсутствия. Действующий профиль реализации.

## Вход и права

Параметры предложения: `date` (YYYY-MM-DD), `type` (код из allowed_types). Только за себя, все роли. Инициатор, согласующий и idempotency_key определяются Go.

## Поведение

Однодневная заявка: date >= локальная дата + notice_period_days. Прямой MCP-write запрещён. После HTTP-confirm Go возвращает action_id, external_id, status=pending_approval и UUID approver. Повторы используют тот же ключ; изменение согласующего требует новой карточки.

## Контракт и ошибки

Точные JSON Schema и примеры: [MCP, раздел 5](../../docs/mcp.md#5-данные-и-json-schema).
Ответ MCP имеет ok/data либо ok/error; коды ошибок и retryable определены
в [разделе 7](../../docs/mcp.md#7-ошибки-и-повторы). Go проверяет права при каждом вызове.
Внутренние ID - UUID; внешний номер заявки сохраняет формат интеграции.
