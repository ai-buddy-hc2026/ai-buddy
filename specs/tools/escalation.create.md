# escalation.create

Передача вопроса наставнику вместе с контекстом (сценарии S-5 и S-6). Действие с эффектом.

## Вход
| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| question | string | да | Вопрос стажёра, без пустых значений |
| context | array | нет | Последние сообщения диалога (до 6), каждое обрезано до 500 символов |

user_id и team_id берутся из токена, наставник определяется по команде и связке стажёр-наставник.

## Выход
```json
{"id": "ESC-17", "status": "open", "assignee": "buddy_ilya"}
```

## Права
Только стажёр.

## Подтверждение
Обязательно. Агент возвращает `action_proposal` (`app/agent/unknown.py`, `escalation_proposal`), интерфейс показывает кнопку «Передать наставнику», вызов выполняет Go после нажатия.

## Ошибки
| Код | Когда |
|---|---|
| policy_denied | роль не стажёр |
| empty_question | пустой вопрос (HTTP 422) |
| buddy_not_assigned | у стажёра нет наставника |
| service_unavailable | сбой сервиса, повторить |

## События
`action_proposed`, `escalation_created`.

## Дальше
Наставник отвечает через `POST /buddy/escalations/{id}/answer`. С флагом `add_to_kb` ответ попадает в базу знаний (S-6).
