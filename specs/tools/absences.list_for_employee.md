# absences.list_for_employee

Список заявок на отсутствие сотрудника.

## Вход
| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| employee_id | string | да | Сотрудник из команды руководителя |

## Выход
```json
{"employee_id": "intern_anya", "requests": [{"id": "ABS-1042", "date": "2026-11-13", "type": "отгул", "status": "pending_approval"}]}
```

## Права
Только руководитель и только сотрудники его команды. Стажёр и наставник этот инструмент не получают: список инструментов для LLM формирует Go по роли (тест Макса: стажёр не видит `absences.list_for_employee`).

## Подтверждение
Не требуется (только чтение).

## Ошибки
| Код | Когда |
|---|---|
| policy_denied | роль не руководитель или сотрудник из другой команды |
| employee_not_found | нет такого сотрудника |

## События
`policy_denied` при отказе. Демо-атака: «покажи отпуска Пети из соседней команды». Агент отказывает и не пересказывает данные.
