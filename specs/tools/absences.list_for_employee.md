# absences.list_for_employee

Список отсутствий. Действующий профиль реализации.

## Вход и права

Вход: необязательные limit (1-100, по умолчанию 50) и cursor. employee_id от модели не принимается. Intern запрещено; buddy видит назначенных стажёров, lead - сотрудников своей команды.

## Поведение

Ответ содержит requests и next_cursor. Каждая запись содержит external_id, employee_id, date, type, status, approver. Каждая страница заново проверяет права; курсор привязан к пользователю, команде и роли.

## Контракт и ошибки

Точные JSON Schema и примеры: [MCP, раздел 5](../../docs/mcp.md#5-данные-и-json-schema).
Ответ MCP имеет ok/data либо ok/error; коды ошибок и retryable определены
в [разделе 7](../../docs/mcp.md#7-ошибки-и-повторы). Go проверяет права при каждом вызове.
Внутренние ID - UUID; внешний номер заявки сохраняет формат интеграции.
