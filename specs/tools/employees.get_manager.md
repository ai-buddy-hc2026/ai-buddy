# employees.get_manager

Согласующий пользователя. Действующий профиль реализации.

## Вход и права

Вход `{}`. Только текущий пользователь; user_id от модели не принимается. Все роли.

## Поведение

Возвращает manager с UUID, name и role либо null. Выбор - активный buddy, затем manager, с исключением самого пользователя. Подтверждение не требуется. Это правило синтетического профиля.

## Контракт и ошибки

Точные JSON Schema и примеры: [MCP, раздел 5](../../docs/mcp.md#5-данные-и-json-schema).
Ответ MCP имеет ok/data либо ok/error; коды ошибок и retryable определены
в [разделе 7](../../docs/mcp.md#7-ошибки-и-повторы). Go проверяет права при каждом вызове.
Внутренние ID - UUID; внешний номер заявки сохраняет формат интеграции.
