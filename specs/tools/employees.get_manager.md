# employees.get_manager

Кто руководитель пользователя. Нужен для ответов «к кому обращаться» и для поля согласующего в заявке.

## Вход
| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| user_id | string | да | Только текущий пользователь |

## Выход
```json
{"user_id": "intern_anya", "manager": {"id": "lead_maria", "name": "Мария"}}
```

## Права
Все роли, только про себя. Руководителя другого сотрудника узнать нельзя.

## Подтверждение
Не требуется.

## Ошибки
| Код | Когда |
|---|---|
| policy_denied | user_id не совпадает с токеном |
| manager_not_found | руководитель не назначен |
