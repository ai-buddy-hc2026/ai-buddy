# absences.get_policy

Правила отсутствий. Действующий профиль реализации.

## Вход и права

Вход `{}`. Все роли, правила своей команды.

## Поведение

Возвращает notice_period_days, requires_approval и allowed_types (code/label). В seed: 3 календарных дня, requires_approval=true, тип day_off. Подтверждение отправки не заменяет согласование заявки.

## Контракт и ошибки

Точные JSON Schema и примеры: [MCP, раздел 5](../../docs/mcp.md#5-данные-и-json-schema).
Ответ MCP имеет ok/data либо ok/error; коды ошибок и retryable определены
в [разделе 7](../../docs/mcp.md#7-ошибки-и-повторы). Go проверяет права при каждом вызове.
Внутренние ID - UUID; внешний номер заявки сохраняет формат интеграции.
