# absences.get_policy

Правила оформления отсутствия: типы, сроки, кто согласует. Нужен, чтобы агент объяснял порядок и не выдумывал его.

## Вход
Нет параметров.

## Выход (предложение, согласовать формат с Василием)
```json
{
  "types": ["отгул", "за свой счёт", "больничный"],
  "min_notice_days": {"отгул": 3, "за свой счёт": 3, "больничный": 0},
  "approver_rule": "непосредственный руководитель",
  "notes": "Заявка оформляется только за себя. Наставника нужно предупредить лично."
}
```

## Права
Все роли.

## Подтверждение
Не требуется (только чтение).

## Ошибки
| Код | Когда |
|---|---|
| service_unavailable | мок сервиса «Отсутствия» недоступен |
