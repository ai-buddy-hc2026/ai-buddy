# Правила для ИИ-агентов

Файл читают Codex, Kimi, Cursor, Copilot, Gemini и другие агенты, которые поддерживают `AGENTS.md`. Claude Code читает его через `CLAUDE.md`.

## Длинные тире запрещены

Во всём, что агент пишет в этом репозитории, используй только обычный дефис `-`.

- Запрещены символы U+2014 (длинное тире) и U+2013 (короткое тире).
- Правило действует везде: код, комментарии, строки в интерфейсе, документы, README, спецификации, коммиты, описания PR и issues, комментарии в ревью.
- Между словами пиши `текст - текст`. Диапазоны тоже через дефис: `3-4 недели`, `50-100 символов`.
- Если меняешь файл, где уже есть длинные тире, замени их на `-` в тех строках, которые трогаешь.

Проверка перед коммитом:

```bash
git grep -nP '[\x{2013}\x{2014}]' -- . ':!*.lock'
```

Команда ничего не должна найти.

## Язык

- Документы и тексты для команды пиши на русском, простым языком, без канцелярита.
- Коммиты в формате `тип: описание`, типы: `feat`, `fix`, `docs`, `test`, `chore`, `refactor`, `ci`.
