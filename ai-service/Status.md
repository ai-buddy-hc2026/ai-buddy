# Отчёт по плану на первый вечер

**Ответственный:** Макс  
**Дата:** 10.11.2026

## 1. Каркас AI-сервиса на FastAPI — частично готово

- Реализован `GET /health`; локальный unit-тест проходит.
- Настройки сервиса загружаются из переменных окружения.
- В `ai-service` есть Dockerfile.
- Проверка проекта настроена через `flake8`, `black` и `isort`, а не `ruff`.
- Полный локальный прогон: unit-тест прошёл, integration-тест завершился ошибкой — отсутствует fixture `mocker`. Поэтому результат успешного полного прогона и готовность всех проверок пока не подтверждены.

**Отчёт:** `/health` отвечает успешно. Утверждение «PR смержен» не подтверждено.

## 2. GitHub Actions — частично готово

- Есть workflow для Python unit- и integration-тестов и отдельный workflow для Python-линтеров.
- Оба workflow настроены на `push` в `main`/`master`; запуска на `pull_request` в них нет.
- Проверок Go и TypeScript в найденных workflow нет.
- Зелёный статус проверок в PR не подтверждён; integration-тест локально не прошёл из-за отсутствующей fixture `mocker`.

**Отчёт:** CI покрывает часть проверок AI-сервиса, но задание целиком не выполнено.

## 3. Контракт Go ↔ Python — не готово

- `docs/ai-contract.md` отсутствует.
- Контракт запроса, Redis-события и согласование Василием не подтверждены.

**Отчёт:** требуется создать документ с согласованным форматом запроса и событиями `token`, `tool_call`, `action_proposal`, `done`, `error`, затем получить подтверждение Василия.

## 4. Доступ к LLM — Ollama отвечает по предоставленному логу

- В предоставленном выводе Ollama вернула ответ на промпт «Выведи что-то маленькое».
- Пример ответа: «Я выведу маленькое слово: „смайл“».
- Текущий integration-тест подменяет поток ответов моками, поэтому сам по себе не проверяет сетевое подключение к Ollama. Работу OpenAI и наличие ключа GigaChat не проверяли.

**Отчёт:** по предоставленному логу отвечает Ollama; требуется отдельная проверка прямого подключения, если нужна независимая фиксация результата.
