# Настройка рабочего окружения

## Что понадобится
Ноутбук с рабочей ОС, доступ к корпоративной почте и мессенджеру, учётная запись в Git-хостинге и трекере задач. Доступы запрашивает наставник или руководитель в первый день.

## Базовый набор
1. Git и аккаунт в репозитории с настроенным SSH-ключом.
2. Docker и Docker Compose для локального запуска сервисов.
3. Редактор или IDE по выбору, с линтером и форматтером проекта.
4. Языки и менеджеры пакетов, которые нужны команде: версии указаны в README репозитория.

## Запуск проекта
1. Склонируй репозиторий командой git clone.
2. Скопируй файл .env.example в .env и заполни переменные. Секреты не коммитятся.
3. Запусти сервисы командой docker compose up.
4. Проверь, что приложение открывается локально, и запусти тесты.

## Если что-то не работает
Сначала посмотри раздел про запуск в README и логи контейнеров. Если не помогло, напиши наставнику: опиши, что делал, и приложи текст ошибки. Типичные проблемы - занятые порты, устаревшая версия Docker и неверные значения в .env.

## Безопасность
Не храни пароли и ключи в репозитории и не отправляй их в общие чаты.
