# Первый pull request

## Подготовка
Выбери небольшую задачу вместе с наставником: исправление опечатки, маленький баг или простой тест. Первый PR должен быть коротким, чтобы быстро пройти ревью.

## Шаги
1. Обнови main и создай отдельную ветку от него. Название ветки отражает задачу.
2. Внеси изменения и запусти линтеры и тесты локально.
3. Сделай понятные коммиты с короткими сообщениями о том, что изменено.
4. Отправь ветку в репозиторий и открой pull request.
5. Заполни описание: что сделано, зачем и как проверить.
6. Назначь ревьюеров и привяжи PR к задаче в трекере.

## Правила
Прямые изменения в main запрещены, слияние идёт только через PR. Если CI красный, исправь причину до ревью.

## Ревью
Читай комментарии спокойно, отвечай на каждый и вноси правки новыми коммитами. Если комментарий непонятен, переспроси.

## После merge
Закрой задачу в трекере, удали ветку и расскажи наставнику, что узнал нового. Первый PR - важный шаг, и это нормально, если замечаний будет много.
